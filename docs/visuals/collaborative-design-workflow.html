Who owns what?

Two desktops · one cloud · local AI when requested
Client / apps/user-application

Werner’s desktop

  • React rendererDraft edits, previews, GSAP animation, graph toolbar, optimistic updates. Not shared authority.
  • Electron main + preloadSecure IPC to the local Rust engine; React never runs a provider directly.
  • AssetsDisplay authorized R2 reference images and approved preview assets.
Server / packages/data-ops

Convex: the shared project

  • Durable stateGuides, selected direction, boards, nodes, edges, tokens, edit history and revisions.
  • Mutations + authCheck workspace access; update targeted nodes/fields. Prevent conflicting same-field edits.
  • Reactive queries + presencePublish saved edits to both clients; maintain expiring viewer/cursor state separately.
  • R2Stores media bytes. Convex stores asset references and permissions, not image data.
Client / apps/user-application

Teammate’s desktop

  • Live subscriptionSees changed tokens, graph edges and the selected guide.
  • Local apps/stage-engineRuns only when that teammate starts AI. Reads shared context, normalizes a proposal, submits to Convex.
  • Other users’ editsTravel via Convex, not through either person’s Rust process.

What happens when someone edits?

Example: change a card shadow or connect two nodes
1 · Local draftReact updates the preview immediately. user-application
2 · Save operationSend a targeted action with ID and revision. Convex mutation
3 · CommitServer checks access and revision; saves that target. data-ops
4 · BroadcastReactive queries deliver the change to both desktops. Convex → React
5 · ConsumeWireframes/export read committed guide and graph. stage-engine / exports
Local · not saved

Open panels, selected node, preview playback, pointer drag and in-progress input. Remains responsive during latency.

Cloud · durable

Light/dark tokens, shadow/motion settings, selected guide, boards, node positions, edges, accepted AI results, history.

Cloud · temporary

Online viewers, selected section and cursors with expiry. Offline desktops cannot edit live until reconnected.

When AI is involved

Stage Engine is not an always-on cloud server
1 · InitiateA teammate clicks Generate in their desktop app.
2 · LoadLocal stage-engine reads authorized shared context and a revision.
3 · GenerateLocal Claude/Codex produces a guide section or graph; Rust normalizes it.
4 · MergeConvex validates the revision. If teammates edited the same target, review/rebase rather than overwrite.
5 · See itBoth clients receive the committed result; previews and exports update.
