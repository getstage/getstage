## Phase 4 — MCP

Users connect their own AI tool to one URL (e.g. `https://mcp.getstage.co/mcp`) and log in with their Stage account once (OAuth). The AI then reads and saves their Stage projects. Estimate: first usable version ~1 week, complete ~2–3 weeks.

### 13. Server and login (2–3 days)
- [ ] MCP server as a Cloudflare Worker (remote, Streamable HTTP) on its own subdomain
- [ ] OAuth with `workers-oauth-provider`, login page uses the existing Convex Auth account
- [ ] Every call acts as that user; only their projects/workspaces are visible
- [ ] Testing + production deployments, secrets as env vars only

### 14. Tools (3–5 days)
- [ ] `list_projects`, `get_project` (brief + every step's current data)
- [ ] `create_project`
- [ ] Save tools per step: Research, Strategy, Style guide, Flows/Sitemap, Wireframes (reuse the existing Convex update mutations)
- [ ] Server-side validation; on a bad input the tool returns what is wrong so the AI retries
- [ ] Step instructions per tool (what a good Research/Strategy/... looks like)
- [ ] Moodboard step — after Mobbin (STA-62)

### 15. Uploads (~1 day)
- [ ] Upload tool for the user's files and images, stored in R2, attached to the project

### 16. Web pages (3–5 days)
- [ ] Home: connect steps per tool (Claude, Claude Code, Cursor, Codex, ChatGPT) with copy buttons / one-click links
- [ ] STA-63 "Connect your AI tool" path leads here
- [ ] Projects list
- [ ] Read-only stage pages per project (what the AI made)
- [ ] Task board
- [ ] Share with clients through the Client Portal (STA-68)

### 17. Monitoring and testing (~2 days)
- [ ] Cloudflare Workers observability + PostHog events per tool call (tool, success/error, duration)
- [ ] End-to-end test in Claude (web/desktop), Claude Code, Cursor, Codex, ChatGPT
- [ ] Ship to testing → Werner/Adrien test → production
