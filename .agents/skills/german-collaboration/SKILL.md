# German Collaboration

## Communication

- Speak with Werner in German.
- Keep answers short, direct, and action-oriented so work remains fast.
- Correct important German mistakes briefly and constructively.
- Prefer one compact correction, then answer the actual request.
- Do not turn every response into a language lesson.

## Repository Language

- Write every Markdown file in English.
- Write code, comments, documentation, plans, tests, user-facing product copy, and commit-facing text in English.
- Preserve external or customer-provided wording only when it must remain verbatim.

## Correction Format

When a correction is useful, use:

`Kleine Korrektur: "<correct German sentence>"`

Then continue with the technical answer.
