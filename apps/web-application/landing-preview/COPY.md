## 11. FAQ (`#faq`)

**Layout:** Use five disclosure rows in a single readable column. Keep each answer short enough to read without losing its question.

**Headline:** Here is how Stage fits into your work.

**Is Stage Mac only?**

Yes, Stage is a native macOS app.

**Does Stage design for me?**

No, Stage does not produce finished designs or high-fidelity screens. It helps you work through the research, decisions, direction and structure that your coding agent builds from.

**Which AI tools does the export work with?**

Stage exports plain Markdown for Cursor, Claude Code, Codex or any coding agent that can read it. AGENTS.md explains the folder and the reading order.

**Do I need Cursor or Claude Code to get value from Stage?**

You can read and use the research, strategy and specifications yourself. A coding agent is where you continue when you want to turn that work into a build.

**Can I use my own component library?**

Yes. Import your own component library from GitHub, or install skills and component libraries from the Stage marketplace in one click. Add your selections to the brief so your coding agent uses them from the first build.
