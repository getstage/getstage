## Purpose

Moodboard is the **visual direction** step after Research + Strategy: import references (upload, image URL, Figma, Refero search), stage them on a shared grid, assign **directions**, then (planned) generate **style guides** per direction for downstream Flows / Wireframes.

## Import pipeline (shipped)

```txt
MoodboardTab → IPC startRun(mode: moodboard, context.source)
  → MoodboardWorkflow (stage-engine)
       → Refero | Figma OAuth | image URL fetch
       → R2 upload (when bytes available)
       → append staged references (isInMoodboard: false) to moodboardArtifact
  → getLatestMoodboardArtifact → resolveAssetContentJson → grid
```

| `context.source` | Engine label | Reference `source` | Notes |
|------------------|--------------|-------------------|--------|
| `refero` / `ai` | Search Refero screens | `url` | Query = **only** the search box text (no Research/Strategy in query) |
| `figma` | Import Figma images | `figma` | Requires Figma connected in Settings |
| `url` / `image-url` | Import image URL | `url` | Direct image URL in paste field |

`providerId: codex` on the IPC request is a **placeholder**; import does not invoke Codex.

### Refero image loading (2026-06-04 fix)

Previously: `refero_get_screen_image` (`full`) often failed → no R2 bytes → references could be saved with `null` optional fields → **Zod parse failed in the renderer** → empty grid despite `run_completed`.

Now:

1. MCP: try `image_size: full`, then `thumbnail`.
2. Fallback: download `image_url` / `thumbnail_url` from search (HTTPS), same pattern as Research URL import.
3. Artifact JSON: omit `imageAssetKey` / `sourceUrl` when absent (never write JSON `null` for Zod `.optional()` fields).
4. Run fails with a clear message if **zero** references could be loaded.

Logs to expect:

```txt
[stage-engine] moodboard import workflow started source=Some("refero")
[stage-engine] Moodboard Refero image loaded from search CDN URL   # fallback path
[stage-engine] Moodboard Refero import staged references reference_count=N
run_completed finalText="Moodboard references imported."
```

Warnings on MCP miss are OK if CDN/R2 path succeeds.

### UI copy caveat

**“Generate with AI”** on the moodboard tab is **Refero screen search**, not an LLM. No Research/Strategy context is injected into the Refero query in V1.

### Direction behavior

Directions are not generated by Refero, Research, Strategy, or the fixture layer. They appear only when the user creates one through **Add to Direction** / **New Direction**. Blank direction names are ignored instead of becoming `Direction N`.

Direction Hub uses real board state:

- reference counts are calculated from items assigned to that direction
- empty directions show an empty-state placeholder, not unrelated images
- clicking a direction name allows inline rename
- renaming updates assigned references and persists through the normal moodboard artifact save path
